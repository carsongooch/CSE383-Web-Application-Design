# CSE 383 - Web Development & API Coursework

This repository contains assignments and labs completed for CSE 383 at Miami University. it documents my work with client-side web development, JavaScript, HTTP requests, APIs, and server-side PHP applications.

The repository is organized by Assignments, Labs, and a separate index of deployed pages and API demonstrations.

[View the deployed webpages and API demonstrations here)](https://github.com/carsongooch/CSE-383/blob/main/Webpage-Links/links.md)

## Coursework

### HTML, CSS, and Javascript

- Built webpages using HTML and CSS, including images, video, and interactive forms.

- Used HTML form controls and validation attributes to collect user input

- Added JavaScript event handling and DOM updates to create interactive webpages
  
### Asynchronous JavaScript and APIs

- Used XMLHttpRequest to make asynchronous GET and POST requests without reloading the webpage

- Built a server-status page that retrieves server and location information, refreshes status data periodically and submits location records

- Created AJAX dashboard with three data views

  - **Weather**: Retrieves current weather conditions from OpenWeather API using a U.S. ZIP code.
  - **Earthquakes**: Retrives significant earthquake information from the USGS GeoJSON feed.
  - **Location**: Submits location and computer information to a Miami university course API and displays returned records

### PHP, Authentication, and REST APIs

- Integrated PHP with Miami University's Central Authentication Service (CAS) using phpCAS to require authentication before displaying a page

- Built a REST API backed by Redis for storing and retrieving data

- Implemented JSON responses and request handling for color preferences, book records, and a random-number endpoint

- Utilized curl requests for exercising the REST API endpoints

### Technologies and Tools

- **Frontend**: HTML5, JavaScript, DOM

- **HTTP and Data**: XMLHttpRequest, JSON, Rest, curl

- **Backend**: PHP, Redis

- **External Data Services**: OpenWeather API, USGS Earthquake GeoJSON feed, Miami University APIs
